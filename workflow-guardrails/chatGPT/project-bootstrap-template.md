Do not use this template to design the product, choose architecture, or plan implementation.

## Bootstrap Exit Criteria

Bootstrap is complete when:

- the project identity is clear enough to begin Discovery
- available source material is listed
- repository conventions are captured or marked unknown
- initial constraints are listed
- non-goals are explicit
- no product design or implementation planning has been introduced

After bootstrap, start the Project Workflow at Discovery.
